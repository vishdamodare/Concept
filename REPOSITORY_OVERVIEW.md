## Getting Started

### Step 1: Clone Repository
```bash
git clone https://github.com/vishdamodare/Concept.git
cd Concept
```

### Step 2: Read Getting Started
Open and follow: **GETTING_STARTED.md**

### Step 3: Setup Development
Follow: **docs/DEVELOPMENT_SETUP.md**

### Step 4: Install Dependencies
```bash
npm install
```

### Step 5: Configure Environment
```bash
cp .env.example .env
# Edit .env with your configuration
```

### Step 6: Start Development
```bash
npm run dev
```

Frontend: http://localhost:3000
Backend: http://localhost:5000

## Quick Commands

```bash
# Development
npm run dev                          # Run all services
npm run dev --workspace=frontend     # Frontend only
npm run dev --workspace=backend      # Backend only

# Testing
npm run test                         # Run all tests
npm run test:coverage                # Coverage report
npm run test:e2e                     # E2E tests

# Code Quality
npm run lint                         # ESLint check
npm run format                       # Format code
npm run type-check                   # TypeScript check
npm run check                        # All checks

# Production
npm run build                        # Build for production
npm start                            # Start production
```
